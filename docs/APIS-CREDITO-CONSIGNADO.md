# APIs de crédito e consignado — realidade para o Leadcheck

## O que ajuda
Existem integrações de Open Finance, bureaus de crédito e plataformas de consignado que podem, com contrato/credenciais e quando aplicável consentimento, fornecer dados financeiros autorizados. Elas não são APIs públicas gratuitas para baixar em massa CPF + contrato + telefone.

## O que o Leadcheck V8 usa
O motor básico não exige nenhuma chave:
- DuckDuckGo HTML público;
- Bing RSS público;
- Google News RSS público;
- páginas públicas indexadas de Reddit, Reclame Aqui, YouTube e Facebook.

Essas fontes são usadas para descobrir **intenção pública**. O sistema preserva a página/trecho para conferência.

## O que não fazemos
- não fazemos consulta em massa de CPF;
- não buscamos saldo, contrato, score ou margem consignável de terceiros;
- não raspamos telefone/e-mail pessoal de redes sociais para montar listas;
- não prometemos uma API gratuita inexistente.

## Estratégia comercial
Para uma assessoria revisional, um sinal público de intenção é mais útil que uma lista fria de pessoas. Exemplos de sinais:
- “juros abusivos no meu financiamento”;
- “minha parcela aumentou”;
- “quero revisar meu contrato”;
- “como reduzir a parcela do financiamento”;
- “problema com empréstimo consignado”.

O Leadcheck deve levar o operador até a fonte pública para verificar o contexto e o canal de contato apropriado antes da abordagem.
