# Leadcheck

CRM funcional + Lead Generator de oportunidades públicas, preparado para Vercel + Supabase.

## Regra central
Um lead utilizável precisa de **nome** e **telefone/celular/WhatsApp ou e-mail**. Resultados sem contato são descartados do Lead Generator e o banco impede gravações sem canal de contato.

## Build
`npm run build`
